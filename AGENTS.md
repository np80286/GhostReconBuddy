# Agent guide

Before changing the interface, read [`docs/PRODUCT-AND-DESIGN-SYSTEM.md`](docs/PRODUCT-AND-DESIGN-SYSTEM.md). It is the shared product profile and the source of truth for cross-page behavior, visual language, evidence handling, and accessibility.

Keep changes app-wide where a pattern is shared. Prefer semantic theme tokens and reusable components over page-specific colors or one-off controls. When adding a new page or changing an existing page, check how the same pattern appears in the other sections and update the shared system when appropriate.

Preserve the application's research boundaries: distinguish sourced facts, direct measurements, derived values, hypotheses, and unknowns. Do not invent game support or real-world weapon matches. Follow the repository README for setup and validation commands.
